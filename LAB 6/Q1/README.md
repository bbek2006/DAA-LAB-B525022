Title: 1D Array Operations and Complexities

Operations Covered:
- Max, First & Second Max
- Mean, Median, Standard Deviation
- Mode
- Remove Duplicates
- Reverse Array
- Partition

Complexity Summary:
- Most operations: O(n)
- Median (sorting): O(n log n)
- Mode/Duplicates (naive): O(n^2)
- Partition: O(n)

Key Insight:
- Linear scan solves most problems efficiently
- Sorting is not always required
- Hashing improves performance to O(n) for mode and duplicates
